# Security and privacy reporting

Agentic Debt Radar is an early-stage public market probe, not a security audit service.

Report a suspected vulnerability, unsafe disclosure, or privacy concern privately to **romispshop@gmail.com**. Include only the minimum information needed to reproduce the concern. Do not place credentials, private repository URLs, personal data, exploit payloads, or non-public findings in a GitHub issue.

The live probe reads public GitHub metadata, visible file-tree paths, and reported file sizes. It does not clone or execute submitted repositories or read their file contents. Its public privacy notice is at <https://agentic-debt-radar.romispshop.workers.dev/privacy.html>.

No bounty, response-time guarantee, or disclosure authorization is offered. Please do not disrupt the live service, exceed its rate limits, access data that is not yours, or test third-party repositories without authorization.
